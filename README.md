A program that outputs exactly one patch note — v2.7.3 fixes the human forgetting why it entered a room the moment it crossed the doorway, then blaming the room for it — for make.fun's "Real-Life Patch Notes: The Comedy Changelog" bounty. A judge model compares entries two at a time, weighing the joke first, then the machine voice, the fit of the line and its freshness.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 -P -s main.py
```
